When a Mermaid workspace is the better fit

Choose a focused editor when the diagram is part of a larger piece of work: an architecture review, a design document, a database discussion, or an incident write-up. Keeping related diagrams on one canvas reduces the friction of jumping between separate snippets and makes it easier to keep visual treatment consistent.

  • You need more than one diagram for the same project or document.
  • You want to try visual themes before exporting an SVG or PNG.
  • You want Mermaid source to stay editable while you refine the presentation.
  • You need a shareable link for a teammate to open without creating an account.

What to keep from a sandbox workflow

Mermaid works best when the source remains the source of truth. Start with a small valid example, make one change at a time, and keep the code next to the rendered result. Pretty Fish follows that same loop rather than replacing Mermaid with a proprietary diagram format.

What Pretty Fish adds

  • Multiple diagrams on a single canvas and multiple pages in one workspace.
  • Theme choices and configuration controls for a more presentation-ready output.
  • SVG and PNG export alongside the original Mermaid source.
  • Reference material, templates, and live rendering in the same browser tab.

A practical migration path

  1. Copy an existing Mermaid block into Pretty Fish.
  2. Check the rendered result and correct syntax while the source is visible.
  3. Add the companion sequence, ER, or architecture diagram on the same page.
  4. Choose a theme that matches the document or presentation where the diagram will appear.
  5. Export the final diagram while retaining the Mermaid code for future edits.
